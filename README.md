## Sobre mim

Olá! 👋 Sou **Gabriel Ferreira**, estudante de **Engenharia de Software na Universidade de Brasília (UnB)**. Meu foco é construir soluções eficientes para problemas complexos, conectando engenharia de software, inteligência artificial e análise de dados.

Dedico-me à pesquisa acadêmica por meio de **Iniciação Científica**, com interesse em **Machine Learning, Deep Learning e Cloud Computing**, e também desenvolvo aplicações web e backend.

- 🎓 **Formação:** Engenharia de Software — UnB.
- 🧠 **Pesquisa e interesses:** Inteligência Artificial, Cloud Computing e Análise de Dados.
- 💻 **Desenvolvimento:** aplicações web e backend, da lógica à implementação.
- 🌱 **Projeto em destaque:** [SafraSmart](https://github.com/diangellis/safrasmart), previsão de produtividade de soja com Machine Learning.
